# Proposing changes to the W2FPL

Ideas, better jokes, holes in the wording, translations: all welcome.

## How

- **An idea or a problem:** [open an issue](../../issues/new/choose). Say what you'd
  change and why. Rough is fine.
- **Your own wording:** open a pull request that edits [`LICENSE`](LICENSE). Keep the
  72-column layout (headings centered, clauses indented like the others).

Discussion happens in the open on the issue or pull request.

## What gets in

The steward (Caleb Gottfried) decides what goes into each version, after discussion.
Proposals are judged on whether they:

1. **Keep it free.** Nothing that adds a condition on the people using the work. A
   joke clause is welcome only if it can't be read as a requirement (see how clause 3
   handles clause 2).
2. **Keep it short.** The WTFPL's charm is that it fits on a napkin.
3. **Keep it funny.** It's a license that says fuck. It should read like one.
4. **Hold up.** Wording that would make a lawyer nervous for a real reason gets fixed,
   not shipped.

## Versions

A published version is never edited: the steward commits to that, and to
versioning every change. Accepted changes are collected into the next
version, which gets a new number, a new date and its own file in [`versions/`](versions/),
and is published at its own URL. Anyone who used an earlier version keeps it.

## Becoming a coauthor

If your proposal (the idea or the wording) goes into a published version, you're a
**W2FPL coauthor**:

- you're added to [`AUTHORS.md`](AUTHORS.md) with what you contributed and the version;
- you're listed at https://snvrkotics.com/w2fpl#coauthors;
- you're covered by the license's credit line, "and the W2FPL coauthors".

Tell us the name (and link, if you want one) to credit you under.

## The fine print

By opening an issue or pull request, you agree that:

- what you contribute is released under the W2FPL itself, so it can go into the
  license (do what the fuck you want to with it, including us);
- you can be credited by the name you give.

That's it.
