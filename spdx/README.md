# SPDX submission files

Prepared ahead of the SPDX License List request, in the format of
[spdx/license-list-XML](https://github.com/spdx/license-list-XML):

- `W2FPL-1.0.xml`: the license in SPDX's XML format (proposed identifier `W2FPL-1.0`).
- `W2FPL-1.0.txt`: the test text, identical to [`../LICENSE`](../LICENSE).

Drafts until SPDX reviews them; the maintainers may ask for changes (for example,
which parts are marked replaceable or optional).
