# SNVRKOTICS Data

An open music metadata graph: artists and the people around them, releases,
recordings, works and labels, with their ISRC, ISWC, ISNI, MusicBrainz and
Wikidata identifiers. Each line of `dump.ndjson` is one entity in Wikidata's JSON
format.

- Live graph: https://data.snvrkotics.com
- Source dump: https://data.snvrkotics.com/dump.ndjson
