# ScanCode LicenseDB entry (draft)

`w2fpl-1.0.LICENSE` is a draft license entry for
[aboutcode-org/scancode-toolkit](https://github.com/aboutcode-org/scancode-toolkit)
(license data lives in `src/licensedcode/data/licenses/`): YAML front matter, then
the license text. ScanCode adds licenses found in real use without waiting for
SPDX, as `LicenseRef-scancode-w2fpl-1.0`; once SPDX lists `W2FPL-1.0`, the
`spdx_license_key` changes to that.

Check the field names against a current entry in that folder before opening the
pull request; the format has changed between ScanCode versions.
